# Навчальне демо камери через WebRTC (macOS)

Це прозорий навчальний приклад: відправник сам відкриває сторінку, натискає кнопку камери й надає дозвіл macOS/браузеру. Прихованого запуску або обходу дозволів немає.

## Файли
- `server.js` — невеликий signaling-сервер WebSocket; він передає лише повідомлення для встановлення WebRTC-з'єднання, не записує й не ретранслює відео.
- `index.html` — сторінка для відправника та переглядача.
- `package.json` — залежність сервера.

## Розгортання сервера
Потрібен Node.js-хостинг, який підтримує постійний вебсервер і WebSocket. Після розгортання через HTTPS використовуйте WSS-адресу, наприклад `wss://your-service.example.com`.

Для локального тесту в терміналі:
```bash
npm install
npm start
```
Це підніме signaling-сервер на порту 3000. Для віддаленого використання його треба розгорнути на доступному з інтернету хостингу з TLS/WSS.

## Як використовувати
1. Розмістіть `index.html` на HTTPS-хостингу або запустіть його через локальний вебсервер. Браузери зазвичай дозволяють камеру лише на HTTPS або localhost.
2. Обидва учасники відкривають сторінку та вводять однакову адресу WSS-сервера й однаковий код кімнати.
3. Відправник вибирає режим «Я передаю свою камеру», натискає «Під'єднатися», а потім «Увімкнути й передавати камеру» і підтверджує запит браузера/macOS.
4. Переглядач вибирає відповідний режим і натискає «Під'єднатися».
5. Щоб завершити, натисніть «Зупинити / від'єднатися».

## Обмеження й безпека
- Використовуйте лише за згодою всіх учасників; інтерфейс явно показує, коли камера вмикається.
- Кімнатний код — лише простий захист від випадкового підключення, не автентифікація для чутливого використання. Не використовуйте цей демопроєкт для приватних/чутливих трансляцій.
- WebRTC використовує публічний STUN-сервер для спроби прямого з'єднання. У деяких мережах може знадобитися налаштований TURN-сервер; без нього з'єднання не гарантовано.
- Сигналінг-сервер у пам'яті: після перезапуску кімнати зникають. Він не зберігає відео.
- Це мінімальний навчальний приклад, а не перевірений production-сервіс.
